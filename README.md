## 🇬🇧 English

### Overview
A modular Python Command-Line Interface (CLI) application for implementing and demonstrating fundamental Data Structures in a practical and organized way.

### Modules & Features
- **Arrays:** Array operations and dynamic data handling.
- **Linked Lists:** Singly and Doubly Linked Lists.
- **Stacks:** Array-based and Linked-List-based Stacks.
- **Queues:** Linear and Linked-List-based Queues.

### How to Run

```bash
git clone https://github.com/Mohammed-Al-hemyari20/Data-Structures-Python-CLI.git
cd Data-Structures-Python-CLI
python appmain.py
```

## العربية
### نظرة عامة

تطبيق منظم بلغة Python يعمل من خلال سطر الأوامر (CLI)، ويهدف إلى تطبيق هياكل البيانات الأساسية بطريقة عملية ومنظمة.

المميزات والوحدات
المصفوفات (Arrays): عمليات المصفوفات وإدارة البيانات.

القوائم الموصولة (Linked Lists): القوائم الموصولة الأحادية والمزدوجة.

المكدسات (Stacks): بناء المكدس بالمصفوفات والقوائم الموصولة.

الطوابير (Queues): بناء الطابور الخطي والقائم على القوائم الموصولة.
